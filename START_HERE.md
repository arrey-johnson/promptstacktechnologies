# Promptstack Technologies Website — Cursor Handoff Pack

## Purpose

This folder is the source-of-truth handoff for building the Promptstack Technologies public website in Cursor.

The website is not a generic corporate brochure and must not be treated as a template-reskin project. It is a commercial acquisition, credibility, content, and Academy platform for Promptstack Technologies.

The implementation must preserve the strategy, brand, information architecture, UX principles, content hierarchy, visual direction, and engineering constraints defined here.

## Critical rule

When a required fact, brand asset, project result, client permission, Academy fee, cohort date, legal statement, contact detail, or licensed font file is missing, use a clearly labeled placeholder in development and request the real asset or fact before production. Never fabricate business proof.

## Brand files

The official Promptstack logo and logo icon already exist and must be supplied by the owner. Do not redraw, regenerate, recolor, distort, rotate, or replace them.

Eurostile is the official brand typeface. Use only properly licensed webfont files supplied by the owner. This pack intentionally does not include font files.

A business-card image supplied during planning is included only as a visual reference.

## Benchmark philosophy

The Ainet template was used only as a quality benchmark for light visual sophistication, whitespace, typography, section composition, restrained motion, and case-study presentation.

Do NOT copy Ainet's desktop navigation. Promptstack must use a proper horizontal desktop navigation with a real Solutions mega-menu and a visible `Start a Project` CTA.

Do not clone any benchmark's copy, imagery, section sequence, source code, or visual identity.
