# 17 — Product Acceptance Criteria

## Global

The website is acceptable only if a first-time business visitor can quickly determine:
- Promptstack is a technology company;
- it works on software, AI/automation, and digital marketing;
- it solves business/operational/growth problems;
- how to evaluate its capability;
- how to start a project.

A learner can quickly determine:
- what Promptstack Academy is;
- what Learn · Build · Ship means;
- available programs;
- how learning is practical;
- how to apply.

## Brand

- official logo used without modification;
- Eurostile used from licensed owner-supplied files;
- official palette respected;
- site is predominantly light;
- no AI cliché visual identity;
- real African human context appears in approved imagery.

## Desktop navigation

At normal desktop width:
- full horizontal nav visible;
- no hamburger;
- Start a Project visible;
- Solutions mega-menu usable with mouse and keyboard;
- Company dropdown usable;
- header feels desktop-native.

## Homepage

- approved section sequence;
- approved working copy or explicitly approved revision;
- problem recognition before detailed capability list;
- all three commercial divisions represented;
- Work uses real content;
- Academy appears as integrated ecosystem;
- final CTA emphasizes starting from the problem.

## Mobile

- no essential content missing;
- CTA accessible;
- navigation easy;
- typography readable;
- forms easy to complete;
- no horizontal overflow;
- no hover dependency.

## Forms

Business and Academy forms:
- server validated;
- Turnstile server verified;
- saved to database;
- success state;
- notification;
- no lost record if email fails;
- privacy acknowledgement;
- attribution fields where available.

## Accessibility

- keyboard complete;
- focus visible;
- AA contrast;
- labels and errors;
- semantic headings;
- reduced motion;
- meaningful alt text.

## Performance

Representative pages target:
- LCP <= 2.5s
- INP <= 200ms
- CLS <= 0.1
- Lighthouse >=90 target

No giant hero asset should make the site unusable on normal mobile networks.

## SEO

- clean URLs;
- metadata;
- canonical;
- sitemap;
- robots;
- Organization schema from verified facts;
- internal linking;
- no thin keyword pages.

## Integrity

Zero fabricated:
- clients;
- metrics;
- testimonials;
- awards;
- partners;
- student outcomes;
- fees;
- dates;
- addresses.

Placeholders must be impossible to mistake for production content.
