# Promptstack ChatGPT Social Prompt Pack

Reusable prompts for generating Promptstack Technologies social content in ChatGPT.

This is a **social-media operating kit**, not website copy. Do not silently rewrite approved homepage messaging on the site from this file. Use this pack only to produce posts, carousels, scripts, and WhatsApp copy.

**Channels:** LinkedIn, Instagram, Facebook, X, TikTok, WhatsApp  
**Language:** English first, then a French version of every asset  
**Primary conversion:** Start a Project  
**Secondary conversion:** Academy Apply

---

## How to use this pack

1. Create a ChatGPT **Project** named `Promptstack Social`.
2. Paste **Section 1 — Master brand system prompt** into Project instructions / Custom instructions.
3. For each job, paste **one short task prompt** from Sections 3–6 and fill the `INPUT` block.
4. Run the **pre-publish QA checklist** (Section 7) before anything goes live.
5. Never paste unverified client names, metrics, testimonials, addresses, or social handles into the `INPUT` block.

Fill these once and keep them in the Project if they are verified. Leave blank if not:

```
Company website: [add when live]
LinkedIn company page: [verified URL only]
Founder LinkedIn: [verified URL only]
Instagram: [verified handle only]
Facebook: [verified URL only]
X: [verified handle only]
TikTok: [verified handle only]
WhatsApp business number: [verified number only]
```

Do not invent missing handles.

## Content mix

Keep social aligned with the website: business-first, Academy present, not a 50/50 split.

| Pillar | Share | Purpose |
| --- | --- | --- |
| Problem recognition | ~40% | Help a decision-maker see lost time, customers, or visibility |
| Solution / outcome | ~20% | Software, AI & Automation, Digital Marketing — outcomes first |
| Process and trust | ~15% | Discover → Define → Design → Build → Launch → Improve |
| Academy | ~15% | Learn · Build · Ship. No employment promises |
| Conversion / founder | ~10% | Start a Project, Apply, founder presence, real work behind the scenes |

**Weekly shape (7 posts):** 3 problem, 1 solution/outcome, 1 process/trust, 1 Academy, 1 conversion or founder.

Approved seed lines. Reuse; do not “improve” into jargon:

- Build better systems. Automate the work slowing you down. Grow with technology.
- Where is your business losing time, customers or visibility?
- You don’t need to know the technical solution.
- Tell us the problem.
- Technology should fit the way your business needs to work — not force your business to fit the technology.
- Learn · Build · Ship.

## Section 7 — Pre-publish QA checklist

Run this on every asset before it goes live. If ChatGPT wrote it, you still own the publish decision.

### Claims and facts

- [ ] No client names, logos, testimonials, or metrics unless owner-verified and in INPUT
- [ ] Proof status matches the copy (the post does not imply results that were not supplied)
- [ ] No Academy job guarantee
- [ ] No invented offices, “across Africa” footprint, awards, or headcount
- [ ] No invented handles, phone numbers, or URLs
- [ ] Dates, fees, cohort names, and event details are verified or removed

### Brand and voice

- [ ] Problem or outcome appears before tools and tech stack
- [ ] Sounds like Promptstack: premium, calm, specific — not a neon AI startup
- [ ] Approved lines were not “upgraded” into jargon
- [ ] One CTA, correct hierarchy (Start a Project vs Apply)
- [ ] Founder posts use only verified identity (Arrey Johnson, Founder & CEO)

### Language

- [ ] English is publish-ready on its own
- [ ] French is natural professional Cameroon/Africa French, not a stiff calque
- [ ] `vous` unless a verified exception
- [ ] Brand names left in English: Promptstack, Learn · Build · Ship
- [ ] Would a Cameroonian business owner share this without embarrassment?

### Visuals and slides

- [ ] Official logo is a supplied file, not AI-generated
- [ ] Palette only #A800E6, #1B263B, #919191, #CBAED3, #FFFFFF
- [ ] Purple is an accent, not the background
- [ ] Small body text is navy, not #919191
- [ ] No robots, brains, circuit heads, neon, or fake dashboards
- [ ] Academy uses more lavender, not a new brand
- [ ] Contrast holds: navy on white, white on navy, white on purple for CTA
- [ ] Slide headlines ≤ 12 words; one idea per slide

### Channel fit

- [ ] LinkedIn / X: no emoji clutter
- [ ] Instagram / TikTok: hook in the first line; hashtags within the cap
- [ ] WhatsApp: sounds like a person; not a pasted ad
- [ ] TikTok B-roll notes are brand-safe
- [ ] Assets that need a URL do not pretend the site path exists if it was not supplied

### If anything fails

Do not ship a rewrite that adds new claims. Either strip the claim or mark `TODO_CONTENT:` and wait for the real fact.
