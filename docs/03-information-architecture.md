## Work

`/work`

Use `Work`, not merely `Portfolio`.

Content:
- Case Studies
- Projects

Case studies explain:
`Context → Problem → Why it mattered → Approach → Solution → Implementation → Outcome → Technology → CTA`

Projects may include smaller builds, internal tools, prototypes, or work that does not yet support a full business-result case study.

Clearly distinguish internal/student/demo work from client case studies.
