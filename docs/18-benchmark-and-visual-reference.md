# 18 — Benchmark and Visual Reference

## Primary benchmark concept

Ainet was selected as a quality reference, not a template to clone.

Useful qualities:
- clean white/light foundation;
- generous whitespace;
- strong typography;
- premium technology presentation;
- restrained movement;
- case-study/work presentation;
- modern composition.

Rejected quality:
- its primary desktop navigation feels too mobile/compressed.

Promptstack desktop navigation must instead be a proper horizontal desktop menu.

## Promptstack-specific improvement over benchmark

Promptstack should be:
- more business-problem focused;
- more human;
- more authentically African;
- more grounded in real product work;
- less generic AI;
- stronger in process/trust;
- stronger in Academy integration;
- more explicit about conversion.

## Visual benchmark test

If a proposed design looks like:
- a Framer template with Promptstack logo pasted on it;
- a generic AI SaaS website;
- a digital agency card grid;
- a purple neon cyber brand;

reject and redesign.

The benchmark target is quality, not imitation.
