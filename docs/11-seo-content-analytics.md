# 11 — SEO, Content, and Analytics

## SEO principle

One clear search/user intent per page.

Do not make the homepage target every service and training keyword.

Use dedicated solution/program/Insight pages.

## URLs

Lowercase, descriptive, concise.

Good:
- `/solutions/ai-automation`
- `/academy/programs/artificial-intelligence`

Avoid keyword-stuffed URLs.

## Technical SEO

Every indexable route should support:
- title;
- meta description;
- canonical URL;
- Open Graph metadata;
- social image;
- logical H1;
- semantic headings;
- index/follow controls;
- breadcrumb where useful.

Generate:
- sitemap;
- robots configuration.

Add Organization structured data using verified company facts only.

## Internal linking

Insight → relevant Solution.
Solution → relevant Work.
Case Study → relevant Solution.
Academy Insight → relevant Program.
Program → Apply.

This is part of both conversion and SEO.

- UTM campaign

## Management funnel

Business:
`Visitors → project form starts → submissions → qualified leads → discovery calls → proposals → won projects → revenue`

Academy:
`Visitors → program views → application starts → applications → admissions → payments → enrolments`

Traffic alone is not success.
